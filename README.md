# 旅迹 · Travel Photo Map

**本地旅行照片地图相册与照片管理工具，支持离线地图、地点分类、自定义背景和备份恢复。Windows x64 桌面版解压即用，原图只读，无需账号。**

把电脑里的旅行照片按地点和类别整理，在地图上浏览省份、城市与旅行足迹，打开地点相册回看旅途中的风景与回忆。

照片始终留在原来的文件夹中。旅迹只读访问原图，不会上传、移动、改名或删除原图。

![旅迹首页演示：旅行地图与照片地点](assets/demo.png)

## 主要功能

| 功能 | 可以做什么 |
| --- | --- |
| 旅行地图相册 | 使用离线地图浏览省份、城市和旅行地点，通过地点封面打开相册 |
| 本地照片管理 | 添加本机目录，手动扫描 JPEG、PNG、WebP，搜索、排序和查看未分类照片 |
| 地点与类别整理 | 批量归类照片，管理旅行地点及地点下的多个类别 |
| 照片查看器 | 大图切换、滚轮缩放、拖动、全屏、缩略图条，以及复制路径和打开所在文件夹 |
| 自定义首页背景 | 从图库选照片，预览并调整取景、缩放和透明度，保存后重启保留 |
| 目录与索引维护 | 重新关联移动后的照片或目录，从图库排除照片并按需恢复 |
| 备份与恢复 | 导出整理信息、地点、类别和背景设置，预览并恢复到空图库 |

离线地图和本地照片整理无需网络或个人 Key。在线地图与地名搜索为可选功能，需要网络和天地图服务端 Key。

## Windows 桌面版：解压即用

桌面版适用于 Windows x64，已内置 Electron 和 Java 21 运行环境，无需另行安装 Java、Node.js 或 Maven，也不需要打开终端。

请选择发布者提供的 `旅迹-Windows-x64-<版本号>.zip` 桌面运行包。GitHub 的 **Code → Download ZIP** 和 **Source code (zip)** 是源码包，需要按下方说明构建。

1. 下载桌面版 ZIP，**完整解压**到本地文件夹。
2. 双击 **旅迹.exe**，等待准备页面结束。
3. 点击**左下角设置齿轮 → 添加目录 → 选择文件夹**，添加照片目录后点击**手动扫描**。

扫描会读取所选目录及其子文件夹。添加目录本身不会开始扫描；以后加入新照片时，再次点击“手动扫描”即可。

首次使用从空图库开始，运行包不包含个人照片或整理数据。用完后关闭窗口，程序会在保存数据后退出；再次双击会唤起已有窗口。

目前已在 Windows 11 x64 实际解压验证。尚未完成未安装开发工具的干净 Windows 环境验收；程序未签名，系统可能提示未识别发布者。

## 数据保存在哪里？如何更新？

桌面版将图库与程序文件分开保存，首次启动时自动创建以下目录：

| 内容 | 默认位置 |
| --- | --- |
| 照片索引、地点、类别、背景设置、缓存、备份和日志 | `%LOCALAPPDATA%\TravelRecording\data\` |
| 在线地图等用户配置 | `%LOCALAPPDATA%\TravelRecording\config\application-local.properties` |

打开**文件资源管理器**，将 `%LOCALAPPDATA%\TravelRecording\data\` 粘贴到顶部地址栏并按回车，即可进入数据目录。它通常位于 `C:\Users\你的用户名\AppData\Local\TravelRecording\data\`。

**更新桌面版：** 先关闭旅迹，等待窗口退出，再将新版 ZIP 解压到另一个文件夹，双击新版 `旅迹.exe`。默认仍读取同一用户图库，原来的照片归类和背景设置会保留；不要删除用户数据目录。

源码 Web 版仍默认使用项目目录中的 `data/`。桌面版不会自动导入或搬迁源码版图库，已有整理结果可按下方备份步骤转入。

<details>
<summary>从源码运行 Web 版或构建桌面 ZIP</summary>

源码需要先生成可运行程序：

1. 准备 Java 21 JDK，并配置 `JAVA_HOME`；安装 Node.js 24。
2. 双击 **Build.cmd**，等待构建成功。首次构建需要联网下载依赖。
3. 运行 **Start.cmd**。之后日常使用不必重新构建。

源码版双击 **Start.cmd** 后，用浏览器打开 [http://127.0.0.1:8080/](http://127.0.0.1:8080/)。源码版数据仍默认在项目 `data/`，停止时按 Ctrl+C；后台服务使用 **Stop.cmd**。开发者可用 **Build-Desktop.cmd** 生成桌面 ZIP，见[桌面构建说明](docs/桌面版开发.md)。

</details>

## 浏览和整理照片

点击左上角 LOGO 返回旅行地图；顶部的**全部照片、未分类照片、旅行地点**用于切换整理入口，左下角设置齿轮用于管理目录、扫描及备份。

**新建地点：** 在地图首页点击“新增地点”，填写名称并选择位置，再添加照片。

**整理照片：** 在相册中批量选择照片，归入地点和类别；也可以直接新建类别。在地点相册中，可选择“在该地点归类”或“归入其他地点和类别”。重新归类会替换原类别；移到其他地点时，会清除旧地点的类别。

**查看大图：** 支持上一张／下一张、滚轮缩放、放大后拖动、全屏和底部缩略图。展开“照片信息”可查看原始路径、打开所在文件夹。

## 更换首页背景

在地图首页点击**更换背景 → 选择照片 → 确定**，进入预览后拖动取景、调整大小和透明度，最后点击**保存并应用**。

背景采用固定 16:9 取景，随页面等比缩放。保存后会保留取景和透明度，同一图库在不同浏览器中共用；其他页面不使用该背景。

## 备份与恢复

在**设置与数据 → 备份与恢复**中点击“导出备份”，保存下载的 ZIP 文件。

备份包含照片的整理信息、地点、类别和首页背景设置，**不包含照片原文件**。请另外备份原图。

目前仅支持恢复到**空图库**，不能合并或覆盖已有图库。恢复后，需再次确认照片目录的访问权限。

### 将原 Web 版的归类转入桌面版

1. 打开原 Web 版，在**设置与数据 → 备份与恢复**中导出备份。
2. 打开桌面版，在空图库中点击**选择备份并预览**，核对后点击**确认恢复到空图库**。
3. 点击**确认目录访问 → 确认并重建缩略图**，允许只读访问原来的照片文件夹。

原来的地点、类别、照片归属和首页背景设置会随备份恢复，原照片无需搬动。两种入口使用不同的数据目录；恢复后各自的修改不会自动同步。如果桌面版已经添加目录或照片，请先使用下面的方法另建空图库。

<details>
<summary>如何用新图库恢复备份？</summary>

桌面版可为 `旅迹.exe` 创建快捷方式，在目标末尾添加空格及 `--travel-user-dir="D:\旅迹新用户目录"`，指定一个全新用户目录，程序会在其中建立 `data` 和 `config`。打开后在设置中选择备份、预览并恢复；不要指向原图库或照片文件夹。

源码版在项目目录打开终端，运行：

```bat
.\Start.cmd -Port 8081 -DataDir ".\data\restore-library"
```

使用一个尚未存放图库数据的新目录。打开 http://127.0.0.1:8081/，进入设置，选择备份并预览，核对后确认恢复，再确认照片目录访问。

</details>

## 使用中可能遇到的问题

- **照片或文件夹移动了：** 单张照片可在失效的照片查看器中“重新定位”；整个目录可在设置中点击该目录的“重新定位”，核对后重新关联。
- **不想收录某些照片：** 选择“从图库排除”，原图仍留在电脑中；可在“设置与数据 → 已排除照片”中恢复。
- **没有网络或个人 Key：** 本地照片整理和离线地图仍可使用。桌面版在线地图配置位于 `%LOCALAPPDATA%\TravelRecording\config\application-local.properties`，填写 `app.geography.tianditu-key=个人服务端Key` 后退出重开。源码版使用项目 `config/` 下的[配置示例](config/application-local.properties.example)。
- **需要保留程序数据：** 桌面版在上述用户目录，源码版在项目 `data/`。复制整个数据目录前请先停止程序，不要仅复制运行中的数据库文件。
- **桌面版看不到原 Web 版的归类：** 两者默认使用不同图库，原有归类仍保存在原 Web 版的数据目录中。按上方步骤导出备份，再恢复到桌面版空图库。
- **启动失败：** 提示中可打开日志文件夹。确认同一图库的其他入口已退出，再重新打开；不要删除锁文件或强停其他 Java 程序。

地图用于旅行记录和位置浏览，不用于导航，也不是经审定的标准地图。来源与许可见[地图资源说明](frontend/public/assets/README.md)。
