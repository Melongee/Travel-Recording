# 旅迹 · 个人旅行地图相册

> 2026-10-23 最新范围：启动自动扫描、地点位置调整和地图资源后续修正已由用户取消；现有手动扫描、坐标编辑及地图功能与资源限制保留，不再将取消项作为交付门槛。

Windows 本机旅行照片相册。Java 服务只读访问你明确添加的照片目录，索引、地点和类别保存到 SQLite。已实现真实照片整理、备份恢复、天地图搜索、文件夹定位及地点删除，完成独立 5,000 张样本的核心验收；正式基础地图资源及完整 PRD 尚未全部完成。

## 直接运行

本机已经准备 Java 21 并生成可运行 JAR：

1. 双击项目根目录 **Start.cmd**，等待控制台显示 `Tomcat started`。
2. 在 Chrome / Edge 打开 **http://127.0.0.1:8080/**。
3. 在“设置与数据”点击“添加目录 → 选择文件夹”，在 Windows 系统窗口选中照片目录，核对回显路径后点击“添加目录”，再点击“手动扫描”。
4. 新建地点，可先“管理类别”，再点击地点内“添加照片”挑选已扫描照片；也可沿用“全部照片”或“未分类照片”的批量归类入口。
5. 停止时在启动窗口按 **Ctrl+C**，再关闭窗口。

查看照片时展开“照片信息”，可复制原始路径或“打开所在文件夹”，在 Windows 资源管理器中选中原文件。照片丢失、目录未确认或无桌面会话时会提示原因，可继续复制路径查找；可设置 `app.desktop.enabled=false` 禁用桌面调用。

照片移动或改名后，在失效照片查看器点击“重新定位此照片”，通过系统窗口选择新文件，核对新旧影像和路径后确认。原照片 ID、地点、类别、排除状态与排序保留；取消不改索引，已被其他记录占用的新路径不能覆盖。核对依据为文件大小、尺寸和旧缩略图，未保存旧原图字节指纹；无旧缩略图时必须人工确认。预览后会再次校验所选文件 SHA-256 防止文件变动。未挂载位置仅授予该单文件访问，不扫描父目录，设置页标为“仅此照片”；备份恢复后也只确认该文件访问。

整个目录移动后，在“设置与数据”的原目录旁点击“重新定位”，用系统窗口选择新目录。预览会区分可恢复、歧义/待核对、未匹配和原路径仍可访问的记录；只默认选中通过影像核对的单一候选。多个候选需明确选定，可点击“核对影像”；缺少旧缩略图时还需勾选人工确认。确认仅更新所选照片的路径，保留 ID、归类、排除和排序；未匹配或跳过的记录继续保留。全部恢复时替换旧挂载，部分恢复时保留旧目录与未恢复记录；新目录在确认后挂载，以后手动扫描会正常收录其中其他照片。取消不写入，文件变化、路径占用或重复目标会拒绝，事务失败整批回滚；原图不移动或改写。

添加目录使用本机 Windows 文件夹选择窗口，不上传文件。选中后可重新选择；取消系统窗口保留此前选中路径，取消添加弹窗不登记目录。确认添加前不会扫描照片，原有目录去重、可读性及符号链接/应用数据目录保护继续生效。服务需运行在当前 Windows 桌面会话；关闭桌面操作或无交互桌面时会提示无法选择。

挂载错误时，在“设置与数据”的对应目录旁点击“移除”，核对未分类、已归类、已排除照片的索引删除数量后确认。移除会删除不再由其他有效挂载目录覆盖的照片索引及归类关联，使其从各相册和已排除列表消失，统计与封面同步更新；电脑中的文件夹和原图保持不动，地点与类别本身保留。重叠挂载仍覆盖的照片会保留并显示保留数量；扫描中需等待完成再移除。以后重新挂载并扫描会新建已删除索引，原归类与排除状态不会自动恢复。

大图查看器支持在照片区域滚轮缩放（50%～400%，以鼠标位置为中心）；放大后超出可视区域时，可按住鼠标左键拖动。缩回可完整显示时自动居中，切换照片重置为 100%；全屏、信息面板和底部缩略图条继续可用。

地点详情和地点列表提供删除入口。确认窗口会显示照片与类别数量；确认后照片回到未分类，地点的类别和关联被移除，原图与照片索引保留。需要保全地点信息时可先导出管理数据备份。

不想收录某些照片时，在“未分类照片”或“全部照片”中批量勾选，点击底部“从图库排除”并确认。排除后不出现在图库、未分类或地点/类别相册，相关数量和封面同步更新，重扫和重启也不会自动加回；原文件保持原位。应用保留排除记录及原有归类，可从“设置与数据 → 已排除照片 → 查看与恢复”批量恢复。排除按已登记路径生效，不是删除原图。

地点内“添加照片”默认显示未分类照片，来源菜单还列出其他各个地点；不提供“全部图库”或当前地点，已排除照片不参与选片。搜索、排序及每页 100 张分页限定在所选来源内，翻页、搜索或切换来源保留已选照片。当前类别会默认选中，也可选择多个或不选；点击“下一步”核对影响后再确认添加。从其他地点移入时清除旧地点类别，当前地点已有照片不受影响。取消不保存，保存失败保留选择以便修改或重试；保存后仍在当前地点，清除照片搜索并保留仍适用的当前类别。

开发验收可能已在后台运行服务；此时直接访问即可。停止后台服务用 **Stop.cmd**。`Start.cmd -Background` 可显式后台运行，日志与 PID 保存在数据目录；普通双击启动会保留控制台。重复启动同一端口及数据目录会提示 `Already running` 并复用原服务。

端口被其他服务占用时，先停止旧服务，或运行 `Start.cmd -Port 8081 -DataDir "D:\旅迹测试数据"` 后访问 http://127.0.0.1:8081/。同时运行两套服务必须使用不同端口和数据目录；数据库目录有进程锁。服务只监听回环地址，不供局域网访问。

已授权并验证 `D:\照片\test` 的 60 张照片。首轮创建过“闭环测试地点”、A/B 测试类别及三张照片的测试归类，后续以你在页面中的修改为准；验收地点信息不代表照片真实地点。

## 数据位置

默认均在项目独立的 **`D:\CodexWorks\Travel-Recording\data`**：

| 路径 | 内容 |
|---|---|
| `library.db`、`library.db-wal`、`library.db-shm` | SQLite 索引与分类；运行时 WAL 文件属于数据库的一部分 |
| `cache/` | 480 像素缩略图、按需生成的 1920 像素预览；均非原图 |
| `backups/` | 页面导出的 ZIP 管理数据备份，以及切换数据库前的恢复快照 |
| `restore/`、`uploads/` | 备份校验/上传临时文件；成功恢复后清理对应校验目录 |
| `logs/application.log` | 服务日志 |
| `console*.log`、`app.pid` | 后台启动的输出与进程记录 |

原始照片仍位于添加的目录，不上传、搬迁、改名、覆盖或删除。文件缺失时保留索引、地点和类别。不要将照片根目录设为项目 `data` 或其祖先目录。

可用 `Start.cmd -DataDir "E:\旅迹数据"` 指定另一个本机数据目录。后台停止时同样传入 `Stop.cmd -DataDir "E:\旅迹数据"`。直接运行 JAR 时默认相对当前工作目录创建 `data`，建议使用脚本以获得固定位置。

## 备份和恢复

在“设置与数据 → 备份与恢复”点击“导出备份”，下载 ZIP；服务器也会在 `data/backups/` 保留一份。备份使用 SQLite 一致性快照，包含目录、照片索引、地点、类别和归属关系，不包含原图、缓存、日志或地图 Key。备份含照片路径和整理信息，应自行妥善保存。

恢复只支持**空图库**，当前版本不合并或替换已有图库：

1. 用独立目录启动，例如 `Start.cmd -Port 8081 -DataDir "D:\旅迹恢复数据"`。
2. 打开对应地址，进入设置，选择 ZIP，核对照片/地点/类别数量及目录，再点“确认恢复到空图库”。最大上传 256 MiB。
3. 恢复后地点和类别立即可查；逐个点击“确认目录访问”，确认路径后重建缩略图。未确认前不读取备份中的原图路径。
4. 原图暂时缺失时仍保留分类。路径变化时，可通过失效查看器的单张重新定位，或设置页的整个目录重新定位恢复关联；先核对候选再确认。

恢复会校验 SHA-256、清单/数据库版本、表结构、SQLite 完整性及关联；切换前保存恢复快照，切换失败尝试回退。也可停服后复制整个数据目录保全数据；不要仅复制运行中的 `.db` 主文件而遗漏 WAL。

当前数据库为 V2（照片排除状态）。已有 V1 图库首次启动新版时，先在 `data/backups/before-upgrade-v1-*.db` 保存一致性快照，再升级；快照失败则不升级，升级失败会停止启动并保留快照。新备份保留已排除状态及归类，预览中的照片记录数包含已排除照片；旧 V1 ZIP 经过原版本结构校验后，也可恢复到新版空图库。

## 天地图配置和离线使用

从[天地图控制台](https://console.tianditu.gov.cn/)申请**“服务端”类型**的 Key，使用 WMTS 底图和地名搜索服务。复制 `config/application-local.properties.example` 为同目录的 `application-local.properties`，填写 `app.geography.tianditu-key`，然后 `Stop.cmd`、`Start.cmd`。实际配置文件被 Git 忽略，也不进入备份；不要将 Key 填到要提交的示例文件。

默认仍为本地基础地图，鼠标悬停地图时可用滚轮缩放；普通窗口和全屏默认视野均可直接切换在线底图。新增/编辑地点时，输入至少 2 个字并停顿约 450 毫秒后自动搜索全国候选，无需先选省份或点击搜索；选中结果自动匹配省份和坐标，再确认保存。离线仍可手动选择省份和位置。瓦片短暂失败会重试，持续失败退回基础地图。浏览器端 Key 不能用于当前 Java 调用，天地图会返回 301012。

无 Key 或断网时可继续本地照片整理、基础地图及手动标点；可在本机配置设置 `app.geography.offline=true`，明确禁止地图外部请求。运行本机应用不依赖在线 CDN。2026-10-22 用户已断网手测确认离线地图正常使用；本地省界来源与结构检验已完成，仍有岛屿/海域覆盖及标签锚点限制，保留交互示意标识；2026-10-23 用户取消新增物理断网及无缓存组合专项，既有离线验证保留，见 [地图服务与离线验证](docs/地图服务与离线验证.md)。

## 从源码构建

需要 Node.js（本机为 24.14.0）和 Java 21+。Maven Wrapper 自动提供 Maven 3.9.11，不需要单独安装 Maven。

1. 先停止正在运行的服务。
2. 双击 **Build.cmd**；首次下载依赖需联网。
3. 构建成功后运行 **Start.cmd**。

构建会执行 `npm ci`、前端测试、TypeScript 检查、Vite 生产构建、后端集成测试，再打包。输出为 `backend/target/travel-recording-0.1.0.jar`，包含页面、API、SQLite 驱动和图片插件。运行 JAR 不需要 Node.js。

本机 `.tools/jdk-21.0.12.1+1` 为已校验的 Eclipse Temurin Java 21，脚本优先使用；没有该工具包时设置 `JAVA_HOME`，或执行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts\Prepare-Java.ps1` 下载官方 Java 21。不修改系统 Java 设置。

开发时：先启动 Java 服务，在 `frontend` 运行 `npm run dev`，访问 http://127.0.0.1:5173/。Vite 仅在本机代理 `/api` 到 8080；生产页面与 API 由 JAR 同源提供。前端使用 HashRouter，刷新地点相册地址也可正常加载。

## 已实现与边界

- 手动登记可读目录、递归增量扫描、规范化路径去重、一个后台扫描任务及进度。
- JPEG/PNG/WebP 解码、EXIF 方向、拍摄时间（存在时）、透明图、损坏图隔离；单图超过一亿像素时保留错误记录，避免异常尺寸耗尽内存。
- 全部/未分类/地点/类别/搜索/排序分页查询；每页 100、API 最大 200，当前页全选。
- 地点创建及编辑、地点内类别创建/改名/删除、批量归类、跨地点清理旧类别。
- 全国足迹标签、省内地点封面来自真实统计；查看器缩略图条和翻页遵守当前查询，并按需加载后续页。
- 重启持久保存、缺失原图保留分类；只按已登记照片 ID 提供资源，Host/Origin 与 CSRF 保护。
- ZIP 一致性备份、内容预览和空图库恢复，恢复目录需重新确认，缩略图可重建。
- 天地图在线底图、地名搜索和坐标来源保存；无 Key、离线或在线异常时保留基础功能。
- 照片详情打开原始文件所在目录，地点删除影响确认与取消。

地点内挑选照片、单张及整个目录重新定位已实现。下一轮按用户新反馈推进；剩余已有图库替换恢复和交付收尾等尚未完成。启动自动扫描、地点位置调整和地图资源后续修正已取消；基础省界继续标记为交互示意并保留覆盖限制。用户已断网手测地图，另通过强制离线服务完成照片浏览与归类。没有账号、Agent、云同步或微服务。

2026-10-23 用户已取消 **10,000～50,000 张专项能力/容量测试**，不再作为交付前置条件；保留已完成的 5,000 张样本记录，不新增照片数量硬性上限，不宣称未经验证的大规模能力。
