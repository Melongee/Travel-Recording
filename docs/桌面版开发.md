# Windows x64 桌面版

桌面版沿用现有 React / Spring Boot / SQLite。后端仍绑定 127.0.0.1，同源提供页面并保留 CSRF、Host、Origin 和 CSP 检查。

## 服务约定

- 后端对规范化后的数据目录持有 OS 文件锁，所有入口在打开数据库前获取锁；恢复时不释放锁。进程结束由 OS 释放，无需删除锁文件。
- 只有存在 `TRAVEL_DESKTOP_TOKEN` 的子进程启用桌面管道模式。Spring 启动及迁移完成后输出 `TRAVEL_DESKTOP_READY=<实际端口>`。桌面使用随机挑战请求 `/api/desktop/identity`，核对自己创建的 PID 和规范数据路径。普通健康接口不能用来认领服务。
- 桌面通过子进程 stdin 写入 `shutdown` 请求退出；父进程退出导致的 EOF 同样关闭服务。该控制通道不暴露为网页关闭接口。
- Spring graceful shutdown 先处理 HTTP 请求；扫描在当前照片操作结束后停止，等待线程完成后才关闭连接池及释放图库锁，避免把未扫描照片标为缺失。
- 既有 V3 升级前快照、迁移失败阻止启动及空图库恢复保护继续使用。

后端针对性验证：`DesktopIdentityTest,DatabaseMigrationsTest,BackupIntegrationTest,HomeBackgroundIntegrationTest`。

## 桌面外壳

`desktop/main.cjs` 使用 Electron 单实例锁；用户根目录先规范化，换程序目录仍唤起同一个窗口。默认用户根目录为 Windows `LOCALAPPDATA/TravelRecording`，子目录 `data` 存图库、缓存、备份和日志，`config/application-local.properties` 为可写持久配置。默认不导入源码 `data/` 或开发配置。源码脚本默认语义不变。

特殊用途可用快捷方式参数 `--travel-user-dir="D:\独立用户目录"` 指定另一用户根目录（不是直接数据库目录），用于隔离验收或空库恢复。不能同时打开同一图库；后端文件锁仍是跨入口最终保护。

启动使用内置 Java 的绝对路径及 `server.port=0`，由 OS 原子分配回环端口，随后校验私有身份。窗口不带 Node 能力、无 preload，开启上下文隔离/沙箱，拒绝新窗口、跨源页面导航、webview 与网页权限请求；仅为已核验同源主窗口放行剪贴板写入，以保留查看器“复制路径”。实际解压包已验证 Clipboard API 写入成功。现有原生目录选择及备份下载继续通过原后端/Chromium。

正常关闭等待服务自行安全退出，不按 PID 文件或进程名杀 Java。主进程异常结束时，子进程通过管道 EOF 自行退出。启动超时、身份错误或服务退出提示错误与日志路径；不会连接 8080 上的其他服务。窗口尺寸持久保存并处理已移除显示器。

`cd desktop; npm test` 使用真实 JAR 和独立小库验证身份、CSRF/Origin、脚本式第二服务拒绝、正常管道退出、父管道 EOF 后释放图库并重开。已在 Windows 本机通过（沙箱内不允许回环连接，需在允许回环的本机进程中执行）。

## 生成 ZIP

开发机准备 Java 21 JDK、Node.js 24 和网络后运行 `Build-Desktop.cmd`。这仅是开发者构建入口；最终用户直接双击 ZIP 内的 `旅迹.exe`。

构建复用 `Build.ps1 -DesktopResources` 的前端测试、类型/构建及后端测试；不修改源资源说明，仅排除生成静态资源中的开发用 README。桌面目录用 npm 锁文件安装，Electron 与 Temurin JRE 用 `runtime-lock.json` 锁定版本、官方来源及 SHA256。Java 保留完整 JRE（包括图像、桌面、SQLite 所需依赖及 legal/NOTICE），不从开发 JDK 裁剪模块。

`desktop/package.cjs` 只复制四个外壳运行文件、JAR、JRE、用户说明及许可材料，并使用与现有 favicon 相同的绿底定位图标。组装后必须存在 java.exe、JVM、modules 与许可；首包发现复制缺失后改为逐文件显式复制，缺失即阻断。Electron 原始许可、Java 全套许可、前端原始许可文本、Maven 后端许可清单及地图来源均保留。

输出在忽略目录 `artifacts/旅迹-Windows-x64-0.1.0.zip`，同目录有 SHA256 文件。已有同名 ZIP 会保留并阻止覆盖，需开发者先另存。每次组装使用独立时间目录。`-SkipAppBuild` 仅用于已有应用构建与检查通过后继续组包，不代替检查。

`scripts/Verify-DesktopPackage.ps1 -Zip <ZIP路径>` 会逐文件核对清单大小与 SHA256、必要运行时及许可文件，并检查 ZIP/JAR 无数据库、开发配置、日志、内部文档及演示照片。打包入口自动执行此检查。该检查通过不代表真实桌面交互或干净 Windows 环境验收。

默认包不带任何图库、Key 或背景；配置第一次启动在用户目录生成。未配置 Key 时离线地图可用。用户数据位置与空库恢复入口见根 README 及包内使用说明。
