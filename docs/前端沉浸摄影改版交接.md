## 4. 页面适配

| 页面 | 美化方向与保留要求 |
|---|---|
| 导航及首页 | 统一深色导航、字级和间距，所有入口可达；地图仍为主体，保留已扩大尺寸，不用巨大Hero将地图推离首屏；最近照片区更突出摄影 |
| 地图 | 协调容器、本地矢量配色和标签，省市界、足迹、选中与地点封面清晰；保留缩放/面包屑、在线切换、滚轮及故障降级，不给在线瓦片强行套影响辨识的滤镜 |
| 地点页 | 真实封面宽幅头图，压图文字加遮罩；高度适中，让类别与照片尽快可见。添加照片、类别管理和编辑清楚；无封面时为纯色空态 |
| 图库及选片 | 保留实用网格密度、搜索、排序、分页、多选及跨来源选择；文件名、时间、归属可读，必要信息不只在悬停时出现。来源仍为未分类及其他地点，不含全部图库或当前地点 |
| 查看器 | 安静深色底与克制工具，默认完整显示，保留滚轮缩放/拖动/全屏/键盘切图及随筛选变化的缩略图条；查看中不自动推拉或强制裁切 |
| 设置及弹窗 | 统一面板、按钮、输入和状态；路径、数量、影响确认、错误可读；保留目录选择/移除、排除/恢复、路径重新定位及备份恢复入口和确认规则 |

封面/卡片可 cover，查看器默认完整适配，不拉伸。使用已有照片API、缩略图和预览；固定容器/比例防跳版，非首屏懒加载，可用已有缩略图作为封面渐进占位。**AVIF/WebP双格式、内联LQIP、新图片后端均不设为本轮门槛**，不全库转码、重建缓存或改写原图。

动效以轻量淡入和状态过渡为主；可选Ken Burns仅用于展示封面，缓慢transform并支持 `prefers-reduced-motion`。地图、选片、表单与查看器操作不添加持续自动动画。
