# 首页背景设置（2026-10-24）

首页的“更换背景”先选择图库照片，再进入固定图框预览。可以拖动取景、以滑块调整 100%～400% 缩放和透明度，也可用方向按钮微调。取消或关闭预览不保存；只有“保存并应用”写入设置。恢复默认、不使用照片也先预览后保存。其他页面不使用该背景。

设置保存在主库 `data/library.db` 的 `home_background` 单行表中，包括模式、照片 ID、透明度、缩放和归一化取景位置。照片 ID 引用图库索引，实际预览地址按当前照片版本生成；不复制、上传或修改原图。不同浏览器访问同一数据目录时共用设置，首页重新聚焦或每 10 秒刷新读取。旧版浏览器 localStorage 背景不自动覆盖共享设置，需要重新选择并保存一次。

V3 迁移仅新增背景设置表，沿用启动升级前的一致性快照保护；失败时停止启动并保留快照。背景随现有 SQLite 备份导出。V1/V2 备份仍先按对应旧版结构检查，再在隔离候选数据库中升级。恢复后背景引用的原图同样须先明确确认目录权限。照片缺失、被排除或索引移除时，首页提示重新选择，保留取景参数，不绕过目录权限读取原图。

预览和首页使用固定 16:9 取景画布及相同的填充算法；窗口大小或浏览器缩放变化时，整块画布按页面宽度等比缩放，保留选定的照片区域，不再根据窗口高度重新裁切。窄窗口的背景区域会等比变矮，下方衔接页面底色。备份只包含索引、归类和设置，不包含照片文件。

验证使用独立小样本库：保存失败回滚、无效参数拒绝、分类与原图哈希/修改时间保持、缺失/排除/恢复后权限、V2→V3 快照、V1/V2 旧备份恢复、背景随备份恢复，以及两阶段界面、拖动缩放、透明度、取消、独立会话和重启后读取。
