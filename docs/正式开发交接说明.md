## 2. 已确定的约束

- 个人、单人、本机 Web 应用，主要使用 Windows + Chrome / Edge。用户采用 vibe coding，由开发对话完成实现、验证及文档维护。
- Java 21 + Spring Boot + MyBatis-Plus + SQLite；前端沿用 React + TypeScript + Vite + Leaflet。现有依赖已构建验证，不为开启新对话而重新选型或批量升级。
- 正式照片和分类来自 API / SQLite，Demo 的 localStorage 不是正式数据来源。
- 原图只读，不上传、移动、重命名、覆盖或删除。用户明确授权的测试目录为 `D:\照片\test`；不自行扫描其他个人目录。
- 照片最多关联一个地点，可关联该地点多个类别；跨地点归类时清理旧类别，文件缺失保留索引与分类。
- 全国地图保留轻量足迹标签，省内显示地点封面；查看器底部缩略图条与当前分类、搜索、排序和翻页范围一致。
- 保留当前视觉风格，按需要逐步拆组件；页面逻辑优化不自动扩展成全站视觉重做。
- 不加入 Agent、账号、多用户、云同步、微服务或自动照片内容识别。不自行发布、部署到公网、创建远程仓库或推送。
- 密钥在 Git 忽略的 `config/application-local.properties`，天地图使用**服务端类型** Key。不要输出密钥，不要将个人数据、备份、缓存和本机证据提交 Git。

## 4. 上一轮地图修复的注意点

- 全屏故障不是 Key 失效。大视窗、低缩放时，Leaflet 的 `noWrap` 单独使用仍会请求越过经度 180° 的无效瓦片。两图层已经显式约束墨卡托世界边界，保留细粒度缩放；不要改回仅 `noWrap` 或用整数缩放规避。
- 瓦片短暂失败按批次完成后重试一次，持续失败退回基础图；切换/移动时清理旧重试。实测包含 2032×1117、2560×1440、低层级及注入故障。
- 名称输入至少 2 字、停顿约 450 毫秒自动全国搜索；不先限定旧省份。候选显示名称、省份、地址，点击或键盘选择后匹配省份和坐标。
- 旧请求支持取消，迟到结果不能覆盖新关键词；保留中文组词保护。真实中文输入法组词过程尚未单独人工实测。
- 不能识别候选省份时要求手选，不能误用上次结果的省份；离线手动选省与地图选点继续可用。
- 内部数值按 WGS84 近似使用，保留天地图原始 CGCS2000 来源，不宣称做过精密坐标转换。
