# 旅迹 · 旅行地图相册 Demo

这是本项目的纯前端交互原型。文件均位于 `/demo`，没有 Java、数据库或真实文件扫描业务。

## 直接体验

本目录已经生成 `dist/`，安装 Node.js 后：

1. Windows 双击 **启动Demo.cmd**。
2. 浏览器会自动打开页面，默认地址为 **http://127.0.0.1:4173/**；如果默认端口被占用，会自动尝试后续端口，以启动窗口中显示的地址为准。
3. 使用完关闭启动窗口，或在窗口按 Ctrl+C。

也可以在本目录运行 `node server.mjs`，再手动打开上述地址。不要直接双击 `dist/index.html`，页面需要本机 HTTP 服务加载模块和地图文件。`server.mjs` 仅提供静态前端文件，不含后端业务，也不读取照片目录。

如果没有自动打开浏览器，复制启动窗口中的地址到浏览器即可。启动失败时窗口会保留，并显示缺少 Node.js、构建文件或端口等具体原因。若手动启动，请先进入 `demo` 目录；也可从其他目录运行启动脚本的完整路径。

## 已实现的交互

- 中国省级地图、全国/省份缩放、地点照片标记和点击进入地点相册。
- 全部照片、未分类、地点图库；文件名/地点/类别搜索、排序和网格密度切换。
- 60 张示例照片记录、12 张本地旅行素材、6 个地点、地点内独立类别。
- 多选归类、多类别筛选、更换地点清除旧类别、取消地点关联。
- 创建、编辑、删除地点；基础地图选点；固定候选的模拟地点搜索。
- 类别新增、改名、删除；删除后保留照片及地点关系。
- 地点内添加示例图库照片。
- 大图、上一张/下一张、键盘左右切换、缩放、全屏和照片信息。
- 示例目录添加、模拟扫描进度、模拟目录断开/恢复及照片不可用状态。
- 浏览器自动保存；演示数据 JSON 导出/恢复；重置演示和空图库体验。
- 窄屏布局、键盘焦点、弹窗关闭与基础无障碍标签。

## 推荐的体验顺序

1. 全国地图展示省界、已收藏省份的高亮，以及“青海 2处”这类轻量足迹标签；悬停可看地点数与照片数。点击省份或标签后显示本省地点缩略图，再点击青海湖进入相册。点击地图左上角“中国”可返回全国视图。
2. 打开“未分类照片”，点击“批量选择”，选几张照片并归入青海湖。
3. 进入青海湖，查看照片数量和类别变化，管理一个自定义类别。
4. 选择一个照片类别后打开大图，底部缩略图条展示当前类别或搜索结果中的照片。可横向滚动、点击缩略图或用左右键切换，当前照片会高亮并自动滚入可见范围；右侧可查看照片信息。
5. 新增“翡翠湖”，在地图上修改坐标，再为它添加照片。
6. 在设置中模拟目录断开，观察图库的不可用状态；模拟恢复后再查看。
7. 导出演示数据，重置或体验空图库，再导入之前的文件。

## 演示边界

- **不读取、上传、移动、改名或删除本机原始照片。** 输入的目录只是示例文字，文件夹定位只展示提示。
- 所有整理操作仅修改当前浏览器的示例状态。清除浏览器站点数据会丢失演示进度，可以事先导出 JSON。
- 图片、拍摄信息、路径和地点关系均用于演示，素材与标注地点无对应关系。
- 地名候选是固定示例，不是实时在线搜索；没有在线详细底图。
- JSON 导入导出仅用于本 Demo，与未来正式版的 SQLite 备份格式不同。
- 图片、脚本、样式和地图资源全部本地提供；本机静态服务正常运行时可断开外网使用，首次加载不需要 CDN。
- 本地图为交互示意，采用 Natural Earth 的 de facto 边界数据，**不是中国标准地图**；正式产品应重新核对或替换合适地图数据。

## 开发与构建

```text
npm install
npm run dev
npm test
npm run build
```

开发地址为 `http://127.0.0.1:5173/`，生产静态体验地址为 `http://127.0.0.1:4173/`。

使用 React、TypeScript、Vite、Leaflet 和 Lucide 图标；具体版本已写入 `package.json` 和锁文件。构建在 Node.js 24.14.0 下验证。构建产物可复用到后续 Java 服务的静态资源目录。

## 目录

```text
src/App.tsx              页面与交互
src/model.ts             数据结构、归类规则、持久化数据校验
src/model.test.ts        分类、删除与数据校验测试
src/TravelMap.tsx        本地 Leaflet 地图
src/ViewerFilmstrip.tsx  大图查看器的横向缩略图条
src/styles.css           页面与窄屏样式
src/map.css              地图样式
src/viewer.css           查看器布局与缩略图样式
public/assets/           离线地图与示例图片
server.mjs               仅静态文件的本机预览服务
dist/                    已构建的可运行前端
```
